# SC-01 precinct map

Live map of **Berkeley, Charleston, and Dorchester** precincts for the November 3, 2026 general election.

**Live site:** https://mwg190.github.io/sc-cd01-bcd-map/

Click a precinct for U.S. Senate, U.S. House (CD-01 or CD-06), statewide offices, and the SC House race assigned to that precinct.

## Enable GitHub Pages (one-time)

If the live URL is not up yet:

1. Open [Settings → Pages](https://github.com/MWG190/sc-cd01-bcd-map/settings/pages)
2. Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)**
4. Save

The site is public. Precinct boundaries are from SC Revenue and Fiscal Affairs via Charleston County GIS. This is not a certified sample ballot — confirm at [scvotes.gov](https://scvotes.gov).
